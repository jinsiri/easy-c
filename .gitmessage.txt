# git commit message template
# 본문과 푸터는 선택 사항입니다.
# 주석은 커밋에 포함되지 않습니다.
##################
# type: Subject (아래에 작성)

# Body(아래에 작성)

# Footer(아래에 작성)
##################
# <Type>
# 타입의 첫 문자는 대문자로 하며, : 뒤에만 space가 있음에 유의
# 추가하고자 하는 type은 아래에 작성해주세요

# Feat: 새로운 기능 추가
# Fix: 버그 수정
# Docs: 문서 수정
# Style: 코드 포맷팅, 세미콜론 누락, 코드 변경이 없는 경우
# Refactor: 코드 리팩토링 (기능은 동일하게 유지, 프로덕션 코드 수정한 경우)
# Test: 테스트 코드, 리팩토링 테스트 코드 추가
# Chore: 빌드 업무 수정, 패키지 매니저 수정, 주석 제거 등 production code와 무관한 부분들 (.gitignore, build.gradle 같은)
# Comment: 주석 추가 및 변경
# Remove: 파일, 폴더 삭제
# Rename: 파일, 폴더명 수정
# Lib: 라이브러리 적용 및 라이브러리 관련 설정 코드

##################
# <Subject>
# 영어로 Subject 작성 시
# Add : 추가
# Remove : 삭제
# Simplify : 단순화
# Update : 보완
# Implement : 구현
# Prevent : 방지
# Move : 이동
# Rename : 이름 변경
##################
